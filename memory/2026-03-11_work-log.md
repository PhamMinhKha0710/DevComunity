### Task 9: SignalR Connection Manager Singleton (COMPLETED)

**Vấn đề trước đó:** Trên trang `/chat`, có **3 kết nối ChatHub** và **2 kết nối PresenceHub** chạy đồng thời (từ ChatContext, chat/page.tsx, ChatWidget).

**Kiến trúc mới:**

```
lib/signalr/
├── connectionManager.ts   # Singleton class quản lý mọi kết nối
└── useHub.ts              # React hook wrap singleton
```

**`SignalRConnectionManager` features:**
- Reference counting: `connect()` tăng ref, `disconnect()` giảm ref, chỉ đóng khi ref=0
- 1 kết nối duy nhất per hub, chia sẻ cho tất cả consumers
- Event bus: `on(hub, event, handler)` / `off(hub, event, handler)`
- `disconnectAll()` cho cleanup
- `accessTokenFactory` đọc token dynamic (fix từ Task 1)

**`useHub(hubName)` hook:**
- Auto connect khi user authenticated
- Auto disconnect khi unmount (giảm ref)
- Trả về: `{ on, off, invoke, connectionState }`

**`useSignalR.ts` cũ** → Re-export từ `useHub` để code cũ vẫn hoạt động.
